# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Riptide, please report it privately by opening a GitHub Security Advisory at:

https://github.com/ChonSong/riptide/security/advisories/new

Do **not** file a public issue. We will respond within 72 hours with a triage assessment.

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | ✅       |
| Older   | ❌       |
